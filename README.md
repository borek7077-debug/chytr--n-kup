# ChytrýNákup – příprava automatizace

Tento repozitář je připravený pro katalog ChytrýNákup.

- Plán aktualizací: **jednou týdně, v pondělí**.
- První ověřený zdroj: **Nářadí-Praha.cz**; použití XML v affiliate katalogu písemně potvrzeno.
- Ostatní zdroje a provizní identifikátory budou zapnuty po kontrole oprávnění a identifikátorů eHUB.
- Repo zatím **není produkční web** a není propojeno s Netlify.
- Automatická kontrola zdroje nepublikuje produktový katalog ani nepřepisuje web.

**Důležité:** Nesdílejte v tomto veřejném repozitáři přístupové tokeny, soukromé XML soubory ani neveřejné údaje. GitHub Actions pracovní postup lze spustit i ručně. Pro automatické publikování bude nutné doplnit ověřenou sestavovací verzi katalogu a propojit GitHub s Netlify.
